# Mwongozo wa Mmiliki (Owner)

## Mara moja tu (mwanzo)
1. `/setup`: tumia code ya usanidi, kisha weka namba yako ya simu na nenosiri.
2. Washa MFA kwa app ya authenticator. **Hifadhi recovery codes** mahali salama nje ya simu yako.
3. **Mipangilio → Maeneo:** Stoo, Duka, n.k.
4. **Fedha → Akaunti:** droo ya kila duka, M-Pesa, benki, na salio la kuanzia la kila moja.
5. **Mipangilio → MauzoTrack → DIROMA:** fuata `docs/MIGRATION.md`.
6. **Timu:** alika wafanyakazi. Mpe kila mmoja code yake **ana kwa ana**, baada ya kumpigia simu kuthibitisha namba ni yake.

## Kila siku (dakika 5)
**Muhtasari wa Biashara:** mauzo halisi, makusanyo, faida ghafi, pesa, madeni na stoki. Ukiona onyo ⚠ la "gharama haijulikani", idhinisha gharama za manunuzi.

## Kila wiki
- **Kituo cha Udhibiti:** angalia ripoti zilizoshindwa, backup ya mwisho, na audit log.
- **Ripoti:** kulinganisha mauzo na makusanyo, umri wa madeni, na mambo yasiyo ya kawaida.
- **Wateja wa Jumla:** wabia waliopitisha muda wa kutoa taarifa, na madeni yanayoiva.

## Mambo ni yako peke yako
- Kuidhinisha gharama za manunuzi na kugawa usafiri, ushuru na clearing.
- Malengo ya mauzo.
- Mipango ya commission, kuiidhinisha na kuilipa.
- Kuongeza, kusimamisha au kuondoa wafanyakazi.
- Akaunti za pesa, P&L na ledger.

## Mfanyakazi akiondoka
**Timu → ⋯ → andika sababu → Ondoa.** Anapoteza ruhusa papo hapo.

## Mfanyakazi akisahau nenosiri
**Timu → ⋯ → andika sababu → Toa code mpya.** Mpe code hiyo ana kwa ana.
